House Price Prediction Using Linear Regression
A beginner-friendly machine learning project that predicts house prices using Linear Regression.

📌 Project Overview
This project uses information about a house such as:

Id
Area
Number of bedrooms
Number of bathrooms
Floors
YearBuilt
Location
Condition
Garage

to predict its price.

🧠 Machine Learning Algorithm
Linear Regression

The model learns the relationship between house features and house prices and then predicts the price of a new house.
